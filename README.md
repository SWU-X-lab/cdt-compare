# 全探测变化觉察任务（CDT Compare）

## 使用
- 组别 1/2：正式实验。可选填主试发放的研究编号（6–64 位英文字母、数字、下划线或连字符，首位为字母/数字，大小写有区别）。需要跨任务配对时重复使用同一个编号；不要填写姓名、手机号等个人信息。留空时，每次开始均自动生成匿名编号。每次打开页面仍生成独立的会话编号。
- 组别 0：调试模式，只下载本地 Excel，不写入 Supabase。
- 正式实验参数仍为记忆阵列 250ms、4/6 个色块、4 组各 20 个试次；左半侧色块表示有变化，右半侧色块表示无变化。
- 如果浏览器退出指针锁定或全屏，或切到后台，本次提前结束，已完成正式试次与正在进行的中断试次下载本地 Excel；不把中断记录写入正式服务器结果。中断与正常超时单独计数。
- Supabase 完整写入失败时保留本地 Excel、提示错误，不删除研究字段重试。若服务器不支持全部字段，合并上线前请先在独立测试库核验表结构。

## 验证
`node --test tests/data-quality.test.cjs`

测试以模拟 DOM、计时器、Excel 接口和 Supabase 运行实际脚本，不提交在线数据。两种入口均支持最终正确率页面和空格结束。请在测试部署上另行手测指针锁定、全屏、后台切换、Excel 实际下载及正式数据字段；当前未连接 JATOS。
